# 5일차 — DPU 비교 시연과 최종 발표

목표: 학생이 설계한 직접 구축 NPU와 AMD DPU(Vitis AI 3.0)를 같은 관점에서 비교하고, 4주차 전체를 보고서·발표로 정리한다.

준비물: `01-setup/3_vitis-ai-docker.md`의 사전 검증 완료 결과 (DPU bitstream, xmodel, 타겟 펌웨어 — **당일 빌드 금지**), 4일차 성능 표.

---

## 오전 — DPU 비교 시연 (강사 진행 + 학생 관찰/기록)

### 순서 (예상 60~90분)

1. **하드웨어 로드**
   ```
   sudo xmutil load_accelerator <dpu앱명>
   xmutil listapps        # Loaded 상태 확인
   ```
2. **동일 모델 준비 확인** — 직접 NPU와 비교 공정성을 위해 같은 MNIST(또는 ResNet18 소형) INT8 모델을 사용합니다.
   - 직접 NPU: `run_inference.py --npu`
   - DPU: VART 예제 앱 (사전 빌드 xmodel)
3. **측정**: 추론 1건당 ms, FPS, (선택) 전력. DPU 측은 앱 내부 타이머 또는 `time` 측정.
4. **자원**: Vivado Utilization에서 DPU(B512) vs 학생 NPU의 LUT/FF/DSP/BRAM 비교 표 작성.

### 학생 기록 시트

| 항목 | 직접 설계 NPU (4×4) | AMD DPU (B512) |
|---|---|---|
| 추론 시간 (ms/건) | | |
| 처리량 (FPS 또는 GOPS) | | |
| LUT / FF / DSP / BRAM | | |
| 클럭 (MHz) | | |
| 네트워크 교체 방법 | RTL 수정 + 재합성 | `.xmodel` 컴파일만 |
| 양자화 도구 | 직접 (numpy 스케일) | Vitis AI Quantizer |
| 지원 연산 | GEMM(FC) 중심 | Conv/Pooling/ReLU 등 ISA 전체 |
| 소프트웨어 스택 | mmap Python 직접 | VART / XRT |

### 관찰 포인트 (시연 중 토론)

1. **성능 격차의 원인**: 어레이 크기(4×4 vs B512의 PE 수), 브랜치·버퍼·명령어 엔진의 유무, DDR 대역 활용.
2. **유연성의 원인**: DPU는 마이크로코드 ISA라 모델만 바꾸면 되고, 학생 NPU는 연산 데이터플로가 하드웨어에 고정.
3. **"공짜로 얻은 것"이 없는 이유**: DPU도 결국은 AMD가 만든 어레이+버퍼+컨트롤러 — 2~4주차에서 배운 구성요소의 대형 통합판임을 강조.
